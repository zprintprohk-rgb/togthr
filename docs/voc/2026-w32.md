## 六问汇总

### Q1: 为什么来？（下载动机）
- LDR couples → 想"感觉更近"
- Finch 用户 → 想要可爱的自我照顾外挂
- Paired/Agapé → 伴侣推荐或想改善关系
- Widgetable → 和朋友一起养宠物 + 装饰手机
- Desktop Pets → 想要桌面陪伴/减压
- **Togthr 机会**: "桌面 + 关系 + 养成"三合一还没有人做

### Q2: 什么让你每天回来？
- Finch → 宠物需要冒险才能成长，断了就长不大
- Widgetable → 宠物需要喂食，widget 一直在屏幕上
- Paired → 每日一问的新鲜感（但内容枯竭后会断）
- Agapé → Premium 内容库驱动
- **Togthr 机会**: 桌面端的"always-on-screen"是天然留存锚点，比手机 widget 更强

### Q3: 什么时候最依恋？
- Finch → 宠物进入新生命阶段
- Widgetable → 和朋友的宠物一起进化
- Replika → AI 记住了我说过的话
- Locket → 伴侣的新照片突然出现在主屏
- **Togthr 机会**: 阶段跃迁 + 关系里程碑 = 双重情感锚点

### Q4: 缺什么？
- Paired/Candle → **内容跑完就没了**
- Widgetable → 语音通话、play dates、更多社交功能
- Couple apps 通用 → 同步稳定性（pairing drops）
- Finch → premium 内容太贵、免费装扮太少
- **Togthr 机会**: 养成系统 = 无限内容引擎，没有"题库枯竭"问题

### Q5: 为什么弃？
- Widgetable → 食物太贵/广告太多，变现策略引发反感
- Paired → 内容重复 + 伴侣停用 = 双人 App 的头号杀手
- Replika → AI 行为不稳定、隐私焦虑、替代品太多
- Finch → 付费墙太硬，免费体验不够
- **Togthr 启示**: ① 不要逼氪 ② 支持单人模式（以防伴侣停用）③ 宠物行为可预测

### Q6: 愿意为什么付钱？
- Agapé → "premium 是留存的必要条件"（免费版不够用）
- Finch → 装扮、稀有宠物、更多冒险
- Widgetable → 食物/金币（但负面感知严重）
- Replika → 记忆能力、深度对话
- **Togthr 定价策略**: 免费版要好到培养习惯 → Premium 提供装扮/皮肤/稀有宠物/深度养成
