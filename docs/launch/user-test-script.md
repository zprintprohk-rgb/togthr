# 10 人用户测试脚本（S5 · W10）— 验收 NPS>50

## 测试对象
- 10 名目标用户（5 名桌面宠物爱好者 + 3 名自我关怀工具用户 + 2 名普通白领）
- 远程 30 分钟 / 人，产品为本地 build 或线上 togthr.life

## P0 验证任务（每任务 3 分钟上限，记录完成/卡住）

| # | 任务 | 通过标准 |
|---|---|---|
| T1 | 打开首页 30 秒内理解产品是什么 | 能用一句话说出"桌面宠物" |
| T2 | 完成建造仪式（/build） | 3 步走完，无卡点 |
| T3 | 喂食一次（/companion Feed） | 饱腹度变化可见 |
| T4 | 对宠物说一句话（/api/chat 前端或 mock） | 收到 20-50 字回复 |
| T5 | 找到定价并说出月付价格 | 说出 $5.49 或本币价格 |
| T6 | 48h 想念测试（预置 lastFed=3 天前） | 看到 miss 状态 |

## NPS 问卷（测试结束）

1. 0-10 分：你有多大可能把 Togthr 推荐给朋友？
2. 最打动你的一个瞬间？
3. 最困惑/想放弃的一个点？
4. 愿意为它付费吗？（$5.49/月）
5. 一句话：它对你来说是"玩具"还是"陪伴"？

## NPS 计算

- Promoters (9-10) / Passives (7-8) / Detractors (0-6)
- NPS = (P - D) / 10 × 100，**验收标准 NPS > 50**（即 ≥8 Promoters 且 Detractors ≤1）
