## 6 个真因（不是昨晚猜的"DNS 污染"）

| # | 真因 | 体感 |
|---|---|---|
| P0-1 | **Tailwind 4 把 `bg-gradient-*` 重命名为 `bg-linear-*`**，项目 108 处没改 → 全站 gradient class 不生成 CSS | **白底**（hero 渐变整个不渲染） |
| P0-2 | `siteConfig.url = 'https://Togthr.com'` + `layout.tsx metadataBase` 都写死错域名（rebrand 尾巴）→ sitemap / canonical / OG 全错 | SEO / sitemap 漂移 |
| P0-3 | `wrangler.toml [vars]` 公共值空字符串 → Supabase client init throw 风险 | 首页 client tree 可能 unmount |
| P0-4 | `deploy.yml` 第 152/160/186 行硬编码 `we2-v3`（rebrand 没改完）→ CI 永远验证错的 worker | CI 验证形同虚设 |
| P0-5 | `src/lib/supabase.ts` module-level `!` 取 env，缺失即 throw | env 漂移即崩 |
| P0-6 | V3 hero `from-[#1a0b2e] via-[#0f0524] to-[#0a0118]` 跟 globals.css `#0B0B1A` 色板不一致 | **颜色不一致**（hero 渐变 vs design token 不同色） |

## 修复执行

### P0-1 — bg-gradient → bg-linear
- 脚本：`.harness/scripts/sed-bg-linear.cjs`
- **109 处替换 / 33 文件 / 0 残留**（grep 验证 + idempotent 验证）
- 写代码：`bg-linear-to-r/br/b/tr/tl/bl/t` 全部生效
- Tailwind 4 在 CSS 里同时生成 6 处 `bg-gradient-to-*` 作为 alias（向后兼容无害）

### P0-2 — 域名统一到 togthr.life

- **build 后 sitemap 输出 `https://togthr.life/sitemap-0.xml`** ✅

- `PAYPAL_CLIENT_ID` / `ALIPAY_APP_ID` / `VAPID_PUBLIC_KEY` / `CRON_SECRET` 保持空（需用户 wrangler secret put）

### P0-4 — deploy.yml worker name
- 3 处 `we2-v3` → `togthr-life`（deployments list / CF API URL / ID 4393fac1 检查）

### P0-5 — supabase.ts lazy init
- 移除 module-level `!` 强解引用
- 新增 `getSupabaseEnv()` 函数：缺失时 throw 友好错误 "missing env: X, Y. Set via wrangler.toml [vars] or wrangler secret put"
- 三个 client 函数（browser / server / edge）改用 `getSupabaseEnv()` lazy 取值

### P0-6 — V3 hero 颜色 → globals.css tokens
- 脚本：`.harness/scripts/sed-tokens-first.cjs`
- **39 处替换 / 10 文件 / 0 残留**
